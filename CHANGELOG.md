# Changelog

All notable changes to Tartan are listed here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-01

The first public release.

### Download

- **Windows**: `Tartan-Windows-Setup.exe`. Installs for your user only, with no admin prompt.
- **macOS**: `Tartan-macOS-arm64.dmg` for Apple silicon, `Tartan-macOS-x64.dmg` for Intel Macs.
- **Linux**: `Tartan-Linux.deb` for Debian and Ubuntu, `Tartan-Linux.AppImage` for everything else.

The installers are not code-signed yet, so Windows and macOS ask once before the first launch. The
README explains what to click.

### What is in it

- **Today**: what is due, what to start, overdue work, your classes and the free time between them,
  with one box to capture anything.
- **Calendar**: a month grid and a day agenda; add, edit, tick off and drag deadlines.
- **Schedule**: weekly classes, typed in or pasted from your school's schedule page.
- **Spaces**: per course (or anything else), with notes, deadlines, a grade sheet and tabs for the
  sites you use.
- **Notes**: Markdown with live KaTeX math, links between notes, tags, search and history.
- **Calendar feeds**: subscribe to any `.ics` link to see events or turn them into deadlines.
- **Quick add** that reads dates, times, repeats and courses from one line, and keeps the words when
  a line is ambiguous instead of guessing.
- **Grades**: a per-course grade sheet that projects your final grade.
- **LeetCode**: a daily problem and a 138-problem ladder.
- **Optional Google Calendar sync** for reminders on your phone.

Everything lives in one folder of plain JSON and Markdown files that you own.
