# Code of conduct

Tartan follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be kind and keep discussion about the work.

To report behaviour in an issue or pull request privately, open the repository's **Security** tab
and choose **Report a vulnerability**. Only the maintainer sees those reports, and they stay
confidential.
